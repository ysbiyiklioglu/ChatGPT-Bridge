# ChatGPT Bridge

A Chrome extension bridge that connects ChatGPT's web interface to CLI agents via the Model Context Protocol (MCP).

```
CLI Agent (opencode) <--stdio--> MCP Server <--WebSocket--> Chrome Extension <--DOM--> ChatGPT
```

## Features

- **Send messages** to ChatGPT and receive responses
- **Upload files** (images, PDFs, code files) directly to ChatGPT
- **Download images** generated by ChatGPT
- **Manage conversations** (new chat, history)
- **Quick actions** (summarize, translate, explain, review, rewrite)

## Prerequisites

- [Node.js](https://nodejs.org) >= 18.0.0
- Google Chrome or Microsoft Edge
- A [ChatGPT](https://chatgpt.com) account (free or paid)

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/ysbiyiklioglu/ChatGPT-Bridge.git
cd ChatGPT-Bridge
```

### 2. Install server dependencies

```bash
cd server
npm install
```

### 3. Install Native Messaging Host

```bash
cd ../native-host
install-host.bat
```

After installation, open `com.chatgpt.bridge.json` and replace `PLACEHOLDER_EXTENSION_ID` with your actual extension ID.

To find your extension ID: go to `chrome://extensions`, enable Developer mode, and copy the ID.

### 4. Load the Chrome Extension

1. Go to `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `extension/` directory from this repository

### 5. Start the server

```bash
cd server
node server.cjs
```

Or use the **Start Server** button in the extension popup.

### 6. Open ChatGPT

1. Go to [chatgpt.com](https://chatgpt.com)
2. Click **Connect** in the extension popup

## MCP Configuration

Add to your `opencode.json`:

```json
{
  "mcp": {
    "servers": {
      "chatgpt-bridge": {
        "command": "node",
        "args": ["/path/to/ChatGPT-Bridge/server/server.cjs"],
        "env": {
          "WS_PORT": "3000"
        },
        "timeout": 620000
      }
    }
  }
}
```

## Available Tools

| Tool | Description |
|------|-------------|
| `chatgpt_send` | Send a message to ChatGPT and get a response |
| `chatgpt_quick` | Quick actions: summarize, translate, explain, review, rewrite |
| `chatgpt_status` | Check connection status |
| `chatgpt_new_chat` | Start a new conversation |
| `chatgpt_history` | Get conversation history |
| `chatgpt_upload` | Upload a file (image, PDF, code) to ChatGPT |
| `chatgpt_images` | List images in the last ChatGPT response |
| `chatgpt_download` | Download an image/file from ChatGPT to your computer |

## Project Structure

```
ChatGPT-Bridge/
  extension/              # Chrome Extension
    background/           # Service worker (WebSocket connection)
    content/              # Content script (DOM interaction)
    popup/                # Extension popup UI
    manifest.json
  server/                 # MCP + HTTP + WebSocket server
    server.cjs            # Main server entry point
    src/                  # TypeScript source
    package.json
  native-host/            # Chrome Native Messaging host
    host.js               # Host process
    host.bat              # Windows launcher
    install-host.bat      # Registry installer
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Extension shows "Disconnected" | Click **Connect** in the popup |
| "ChatGPT tab not found" | Open [chatgpt.com](https://chatgpt.com) in Chrome |
| "Content script not responding" | Refresh the ChatGPT tab (F5) |
| Server won't start | Make sure port 3000 is not in use by another process |
| Native host not found | Run `install-host.bat` again and set your extension ID |
